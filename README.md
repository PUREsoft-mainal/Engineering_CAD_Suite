# Engineering CAD & Physics Suite
منظومة هندسية وفيزيائية متكاملة مفتوحة المصدر لتفريد الصاج، تصميم الجمالونات، حساب الجيربوكس والتروس، تحويل الوحدات المحلية والفيزيائية، ورسم الدوائر الإلكترونية.

## المميزات الرئيسية
- **تفريد الصاج (Sheet Metal):** حساب المسلوب (Frustum) والخزانات والدوائر مع معاينة بصرية وتصدير ملفات AutoCAD DXF.
- **الجمالونات (Trusses):** حساب أطوال القوائم والشكالات المائلة وتصدير مخطط التقطيع DXF.
- **التروس والجيربوكس (Gears & Gearbox):** تصميم جيربوكس متعدد المراحل وتحديد عدد الأسنان والأقطار والاتجاهات مع الترس الوسيط (Idler).
- **المعاينة البصرية 2D:** عرض فوري للرسومات الهندسية داخل التطبيق قبل التصدير.
- **الفيزياء والوحدات:** دعم الوحدات المصرية (الفدان، القيراط، السهم، الويبة، الكيلة، القصبة) والثوابت الذرية.

## طريقة التشغيل
1. تثبيت المكتبات:
   `pip install -r requirements.txt`
2. تشغيل الواجهة الرسومية:
   `python main_gui.py`
